1. Zugang

Einmalig: Auf github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Haken bei repo und workflow → Token erzeugen und hier einfügen. Er bleibt nur in diesem Browser gespeichert. (Der Haken bei workflow wird für die Android-App-Funktion gebraucht.)
